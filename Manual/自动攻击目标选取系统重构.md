# 自动攻击目标选取系统重构

请帮忙实现一个新的自动攻击目标选取逻辑！
  - 现存的逻辑比较复杂、零散（说白了写的很烂），请先整理一下现存的零散逻辑。大体上来讲，现存的逻辑优先选取上次攻击过的目标。
  - 但这样不好处理切换目标（如当前目标消失的回合），有时会因为没有目标而跳过回合。所以请实现一个新的逻辑（对于伤害输出者）：

## 第一部分：项目架构基础

### 1.1 miniRAID 三层架构

miniRAID 使用了一个清晰的三层架构模式：

```
ScriptableObject Layer (数据模板层)
    ↓
Runtime State Layer (运行时逻辑层)
    ↓
Renderer Layer (渲染表现层)
```

**关键原则**：
- **ScriptableObject (SO)**: 不可变的数据模板，在Unity编辑器中配置
- **Runtime State**: 运行时的游戏逻辑和状态，可以修改
- **Renderer**: 纯粹的视觉表现，不包含游戏逻辑

**示例**：
- `ActionDataSO` (模板) → `RuntimeAction` (运行时) → UI显示
- `BuffSO` (模板) → `Buff` (运行时) → 图标显示

### 1.2 关键类简介

#### MobData
代表游戏中的一个单位（玩家角色、敌人、盟友等）。

**位置**: `Assets/Scripts/Backend/MobData/MobData.cs`

**关键属性**：
- `health`, `maxHealth`: 生命值
- `unitGroup`: 单位阵营 (Player/Enemy/Ally)
- `Position`: 3D坐标 (Vector3)
- `mainWeapon`: 主武器
- `actions`: 该单位拥有的所有行动列表

**关键事件**：
- `OnDamageDealt`: 当该单位造成伤害时触发
- `OnDamageReceived`: 当该单位受到伤害时触发
- `OnActionPrecast`: 行动执行前触发
- `OnActionPostcast`: 行动执行后触发

#### RuntimeAction
代表一个可执行的行动（攻击、技能、治疗等）。

**位置**: `Assets/Scripts/Backend/SOCore/Action/ActionDataSO.cs` (第511-649行)

**关键属性**：
- `actionData`: 指向对应的ScriptableObject模板
- `LastTarget`: **当前存储的上次攻击目标**
- `power`, `auxPower`: 计算后的威力值

**关键方法**：
- `QueryTarget(MobData source)`: 查询当前应该攻击的目标
- `_SetLastTarget(target)`: 设置上次攻击的目标

### 1.3 事件系统机制

miniRAID 使用了一个强大的事件驱动系统。任何系统都可以监听 `MobData` 上的事件。

**订阅事件的标准模式**：
```csharp
public override void OnAttach(MobData mob)
{
    base.OnAttach(mob);
    mob.OnDamageDealt.AddListener(OnMyDamageHandler);
}

// CRITICAL: 必须在移除时取消订阅，否则会导致内存泄漏！
public override void OnRemove()
{
    parent.OnDamageDealt.RemoveListener(OnMyDamageHandler);
    base.OnRemove();
}

private IEnumerator OnMyDamageHandler(MobData mob, Consts.DamageHeal_Result info)
{
    // info.source: 伤害来源（造成伤害的单位）
    // info.target: 伤害目标（受到伤害的单位）
    // info.value: 实际伤害值
    yield break;
}
```

**重要提示**：
- 事件处理函数都是 `IEnumerator` 类型（协程）
- `yield break` 表示协程结束
- `yield return new JumpIn(...)` 用于调用其他协程

## 第二部分：现有目标选取系统分析

### 2.1 系统概览

当前的自动攻击目标选取系统分散在多个文件中，主要包括：

| 组件 | 文件路径 | 职责 |
|------|---------|------|
| `ActionTargetPicker` | `Assets/Scripts/Backend/SOCore/Action/ActionTargetPicker.cs` | 定义目标选取策略 |
| `Databackend.AimOnTarget()` | `Assets/Scripts/Backend/Databackend.cs` (1302-1318行) | UI点击时设置所有玩家的目标 |
| `PlayerAutoAttackAgentSO` | `Assets/Scripts/MobBehaviour/TurnSlices/Agents/PlayerAutoAttackAgentSO.cs` | 执行玩家自动攻击 |
| `RuntimeAction.LastTarget` | `Assets/Scripts/Backend/SOCore/Action/ActionDataSO.cs` (530行) | 存储上次攻击的目标 |

### 2.2 当前工作流程

**完整流程图**：

```
[1] 玩家点击敌人
    ↓
[2] Databackend.AimOnTarget(targetMob) 被调用
    ↓
[3] 遍历所有玩家角色，设置它们的 mainWeapon.GetRegularAttackSpell().LastTarget = targetMob
    ↓
[4] 自动攻击回合开始
    ↓
[5] PlayerAutoAttackAgentSO.TryCastRegularAttack(mob) 执行
    ↓
[6] 调用 mob.mainWeapon.QueryTarget(mob)
    ↓
[7] QueryTarget() 内部调用 actionData.targetPicker.Pick(source, this)
    ↓
[8] FollowLastPicker.Pick() 返回 ract.LastTarget
    ↓
[9] 如果目标有效，执行攻击；如果无效(null)，跳过此次攻击
```

### 2.3 核心代码分析

#### 2.3.1 FollowLastPicker - 当前的目标选取器

**文件**: `ActionTargetPicker.cs` (第66-78行)

```csharp
public class FollowLastPicker<TSpellTarget> : ActionTargetPickerBase<TSpellTarget>
    where TSpellTarget : SpellTarget
{
    public override TSpellTarget Pick(MobData source, RuntimeAction<TSpellTarget> ract)
    {
        // 检查上次目标是否仍然有效
        if (ract.LastTarget is not { Valid: true })
        {
            return null;  // 目标无效，返回null
        }

        return ract.LastTarget;  // 返回上次的目标
    }
}
```

**问题点**：
- ✅ 简单清晰
- ❌ 目标存储在 `RuntimeAction` 上，而不是 `MobData` 上
- ❌ 没有备选目标（fallback）机制
- ❌ 目标失效时返回 null，导致跳过攻击

#### 2.3.2 AimOnTarget - 设置所有玩家的攻击目标

**文件**: `Databackend.cs` (第1302-1318行)

```csharp
public void AimOnTarget(MobData targetMob)
{
    // 获取所有玩家角色
    var mobs = Globals.backend.allMobs.Where(x => x.unitGroup == Consts.UnitGroup.Player);

    foreach (MobData mob in mobs)
    {
        // 获取主武器的普通攻击
        RuntimeAction<SingleMobTarget> ratk = mob.mainWeapon?.GetRegularAttackSpell()
            as RuntimeAction<SingleMobTarget>;

        if (ratk?.data != null)
        {
            // 验证目标是否可达
            SingleMobTarget validTarget = ActionHelpers.ValidTargetFinder
                .FindValidSingleMobTarget(mob, targetMob, ratk);

            if (validTarget != null)
            {
                ratk._SetLastTarget(validTarget);  // 设置LastTarget
            }
        }
    }
}
```

**特点**：
- 所有玩家角色的目标被统一设置为同一个敌人
- 适合团队集火打法
- 但缺乏个体目标管理

#### 2.3.3 TryCastRegularAttack - 执行自动攻击

**文件**: `PlayerAutoAttackAgentSO.cs` (第68-96行)

```csharp
protected IEnumerator TryCastRegularAttack(MobData mob)
{
    // 检查1: GCD冷却
    if(mob.IsInGCD(GCDGroup.RegularAttack))
        yield break;

    // 检查2: 是否有武器
    if(mob.mainWeapon == null)
        yield break;

    // 【关键】获取目标
    SpellTarget target = mob.mainWeapon.QueryTarget(mob);

    // 检查3: 是否有目标
    if(target == null)
        yield break;  // ❌ 没有目标就跳过攻击

    RuntimeAction ract = mob.mainWeapon.GetRegularAttackSpell();

    if(ract == null)
        yield break;

    // 执行攻击
    yield return new JumpIn(mob.DoAction(ract, target));
}
```

**问题分析**：
- 当 `QueryTarget()` 返回 null 时，直接跳过攻击
- 没有尝试寻找新目标的逻辑

### 2.4 现有系统的设计缺陷

根据代码注释 (ActionTargetPicker.cs 第64-65行)，开发者已经意识到问题：

```csharp
// TODO: Move the logic to MobData / Weapon in a better way?
// Or change to a enemy-priority + target-mob system with each mob
// favoring their previously attacked mobs?
```

**主要问题总结**：

| 问题 | 当前状况 | 影响 |
|------|---------|------|
| 目标存储位置 | 存储在 `RuntimeAction` 上 | 多武器职业（如Grimoire）无法正确工作 |
| 集火机制 | 所有玩家攻击同一目标 | 无法实现个体化目标偏好 |
| 目标失效处理 | 返回null，跳过回合 | 当目标死亡时浪费行动机会 |
| 目标优先级 | 无优先级系统 | 无法智能选择下一个目标 |

## 第三部分：新系统设计方案

### 3.1 设计目标

**核心需求**：
1. ✅ 每个角色独立记录自己造成过伤害的敌人列表
2. ✅ 按时间戳排序（最近伤害的优先）
3. ✅ 自动切换到可用目标（第一个不可用时用第二个）
4. ✅ 已切换后不会自动切回（避免反复横跳）
5. ✅ 只影响伤害输出者，治疗/支援逻辑不变

### 3.2 架构设计

**新增组件**：

```
MobData (扩展)
  └─ DamageTargetTracker (新增)  // 目标追踪器
        ├─ List<DamageTargetRecord> damagedTargets  // 伤害记录列表
        └─ GetPreferredTarget() 方法  // 获取优先目标

DamageTargetRecord (新增结构体)  // 单条伤害记录
  ├─ MobData target  // 目标单位
  └─ float timestamp  // 时间戳

DamageTrackingTargetPicker (新增)  // 新的目标选取器
  └─ Pick() 方法  // 使用DamageTargetTracker来选择目标
```

### 3.3 数据结构设计

#### 3.3.1 DamageTargetRecord

```csharp
[System.Serializable]
public struct DamageTargetRecord
{
    public MobData target;        // 被伤害的目标
    public float timestamp;       // 伤害时间（使用 Time.time）

    public DamageTargetRecord(MobData target, float timestamp)
    {
        this.target = target;
        this.timestamp = timestamp;
    }

    // 检查目标是否仍然有效（存活且可达）
    public bool IsValid(MobData source, RuntimeAction action)
    {
        if (target == null || target.isDead)
            return false;

        // 使用现有的目标验证系统
        var validTarget = ActionHelpers.ValidTargetFinder
            .FindValidSingleMobTarget(source, target, action);

        return validTarget != null;
    }
}
```

#### 3.3.2 DamageTargetTracker

```csharp
using System.Collections.Generic;
using System.Linq;
using Sirenix.OdinInspector;

[System.Serializable]
public class DamageTargetTracker
{
    // 使用List而不是Dictionary，因为需要保持时间顺序
    [ShowInInspector, ReadOnly]
    private List<DamageTargetRecord> damagedTargets = new List<DamageTargetRecord>();

    private MobData owner;  // 拥有者（用于事件订阅）

    public void Initialize(MobData owner)
    {
        this.owner = owner;

        // 订阅伤害事件
        owner.OnDamageDealt.AddListener(OnDamageDealt);
    }

    public void Cleanup()
    {
        if (owner != null)
        {
            owner.OnDamageDealt.RemoveListener(OnDamageDealt);
        }
    }

    /// <summary>
    /// 当造成伤害时，记录目标
    /// </summary>
    private IEnumerator OnDamageDealt(MobData mob, Consts.DamageHeal_Result info)
    {
        // 只记录直接伤害（非间接伤害如DOT）
        if (info.flags.HasFlag(Consts.DamageHealFlags.Indirect))
            yield break;

        // 只记录敌方目标
        if (info.target.unitGroup == owner.unitGroup)
            yield break;

        RecordDamageTarget(info.target);
        yield break;
    }

    /// <summary>
    /// 记录或更新一个伤害目标
    /// </summary>
    public void RecordDamageTarget(MobData target)
    {
        // 移除旧记录（如果存在）
        damagedTargets.RemoveAll(r => r.target == target);

        // 添加新记录（时间戳为当前时间）
        damagedTargets.Add(new DamageTargetRecord(target, Time.time));

        Globals.logger?.Log($"[DamageTargetTracker] {owner.nickname} recorded damage to {target.nickname}");
    }

    /// <summary>
    /// 获取优先攻击的目标
    /// </summary>
    public MobData GetPreferredTarget(RuntimeAction action)
    {
        // 按时间戳降序排序（最近的在前）
        var sortedTargets = damagedTargets
            .OrderByDescending(r => r.timestamp)
            .ToList();

        // 寻找第一个有效目标
        foreach (var record in sortedTargets)
        {
            if (record.IsValid(owner, action))
            {
                return record.target;
            }
        }

        // 没有找到有效目标
        return null;
    }

    /// <summary>
    /// 清空所有记录（用于战斗重置等场景）
    /// </summary>
    public void Clear()
    {
        damagedTargets.Clear();
    }
}
```

### 3.4 目标选取器设计

#### 3.4.1 DamageTrackingTargetPicker

```csharp
namespace miniRAID.Weapon
{
    /// <summary>
    /// 基于伤害历史的目标选取器
    /// 优先选择最近伤害过的敌人
    /// </summary>
    public class DamageTrackingTargetPicker : ActionTargetPickerBase<SingleMobTarget>
    {
        public override SingleMobTarget Pick(MobData source, RuntimeAction<SingleMobTarget> ract)
        {
            // 尝试从伤害追踪器获取目标
            if (source.damageTargetTracker != null)
            {
                MobData preferredTarget = source.damageTargetTracker.GetPreferredTarget(ract);

                if (preferredTarget != null)
                {
                    // 找到有效目标，构建 SingleMobTarget
                    var target = ActionHelpers.ValidTargetFinder
                        .FindValidSingleMobTarget(source, preferredTarget, ract);

                    if (target != null)
                    {
                        return target;
                    }
                }
            }

            // 没有找到历史目标，返回 null
            // （在这种情况下，上层逻辑应该寻找新目标或跳过攻击）
            return null;
        }
    }
}
```

**保留的功能**：
- `AimOnTarget()` 仍然可以用于手动指定目标
- 治疗职业使用 `HealerSingleMobPicker`（不受影响）

**修改的流程**：

```
[1] 战斗开始，MobData 初始化 DamageTargetTracker
    ↓
[2] 玩家角色攻击敌人A，造成伤害
    ↓
[3] OnDamageDealt 事件触发 → DamageTargetTracker 记录 (敌人A, timestamp1)

[6] 检查 damagedTargets 列表，找到最近的有效目标（敌人A）

    ↓
[8] 返回有效目标，执行攻击
```

#### Step 3: 创建 DamageTargetTracker

**新建文件**: `Assets/Scripts/Backend/TargetTracking/DamageTargetTracker.cs`

```csharp
using System.Collections;
using System.Collections.Generic;
using System.Linq;
using Sirenix.OdinInspector;
using UnityEngine;

namespace miniRAID
{
    /// <summary>
    /// 追踪一个单位造成伤害的所有敌方目标
    /// 用于智能选择下一个攻击目标
    /// </summary>
    [System.Serializable]
    public class DamageTargetTracker
    {
        [ShowInInspector, ReadOnly]
        [ListDrawerSettings(ShowIndexLabels = true)]
        private List<DamageTargetRecord> damagedTargets = new List<DamageTargetRecord>();

        [System.NonSerialized]
        private MobData owner;

        /// <summary>
        /// 初始化追踪器并订阅事件
        /// </summary>
        public void Initialize(MobData owner)
        {
            this.owner = owner;
            owner.OnDamageDealt.AddListener(OnDamageDealt);
        }

        /// <summary>
        /// 清理资源并取消订阅事件
        /// CRITICAL: 必须调用，否则会导致内存泄漏
        /// </summary>
        public void Cleanup()
        {
            if (owner != null)
            {
                owner.OnDamageDealt.RemoveListener(OnDamageDealt);
            }
        }

        /// <summary>
        /// 事件处理：当owner造成伤害时记录目标
        /// </summary>
        private IEnumerator OnDamageDealt(MobData mob, Consts.DamageHeal_Result info)
        {
            // 只记录直接伤害（排除DOT等间接伤害）
            if (info.flags.HasFlag(Consts.DamageHealFlags.Indirect))
            {
                yield break;
            }

            // 只记录敌方目标（不记录友军伤害）
            if (info.target.unitGroup == owner.unitGroup)
            {
                yield break;
            }

            // 实际伤害值大于0才记录
            if (info.value <= 0)
            {
                yield break;
            }

            RecordDamageTarget(info.target);
            yield break;
        }

        /// <summary>
        /// 记录或更新一个伤害目标
        /// 如果已存在，会更新其时间戳
        /// </summary>
        public void RecordDamageTarget(MobData target)
        {
            if (target == null)
                return;

            // 移除该目标的旧记录
            damagedTargets.RemoveAll(r => r.target == target);

            // 添加新记录，时间戳为当前时间
            damagedTargets.Add(new DamageTargetRecord(target, Time.time));

            // Debug日志（可选）
            if (Globals.logger != null)
            {
                Globals.logger.Log($"[DamageTargetTracker] {owner.nickname} damaged {target.nickname} at {Time.time:F2}");
            }
        }

        /// <summary>
        /// 获取优先攻击的目标（最近伤害过的有效目标）
        /// </summary>
        public MobData GetPreferredTarget(RuntimeAction action)
        {
            // 按时间戳降序排序（最近的在前）
            var sortedTargets = damagedTargets
                .OrderByDescending(r => r.timestamp)
                .ToList();

            // 寻找第一个有效目标
            foreach (var record in sortedTargets)
            {
                if (record.IsValid(owner, action))
                {
                    return record.target;
                }
            }

            // 没有找到有效目标
            return null;
        }

        /// <summary>
        /// 清空所有记录（战斗结束或重置时调用）
        /// </summary>
        public void Clear()
        {
            damagedTargets.Clear();
        }

        /// <summary>
        /// 获取当前记录的目标数量（用于调试）
        /// </summary>
        public int GetTargetCount()
        {
            return damagedTargets.Count;
        }
    }
}
```

**重要注意事项**：
- `[System.NonSerialized]` 标记 `owner`：因为 `owner` 会在 `MobData` 中设置，形成循环引用
- `ShowInInspector` 让你在运行时可以在Inspector中看到目标列表
- `Cleanup()` 必须被调用，否则会有内存泄漏

**文件**: `Assets/Scripts/Backend/SOCore/Action/ActionTargetPicker.cs`

```csharp
namespace miniRAID.Weapon
{
    // ... 现有的 FollowLastPicker, SelfPicker, HealerSingleMobPicker ...

    /// <summary>
    /// 基于伤害历史追踪的目标选取器
    /// 优先选择最近造成过伤害的敌人
    /// 适用于DPS职业的自动攻击
    /// </summary>
    [System.Serializable]
    public class DamageTrackingTargetPicker : ActionTargetPickerBase<SingleMobTarget>
    {
        /// <summary>
        /// 当没有伤害历史时，是否回退到 LastTarget
        /// </summary>
        [SerializeField]
        private bool fallbackToLastTarget = true;

        public override SingleMobTarget Pick(MobData source, RuntimeAction<SingleMobTarget> ract)
        {
            // 尝试从伤害追踪器获取目标
            if (source.damageTargetTracker != null)
            {
                MobData preferredTarget = source.damageTargetTracker.GetPreferredTarget(ract);

                if (preferredTarget != null)
                {
                    // 找到有效的历史伤害目标
                    var target = ActionHelpers.ValidTargetFinder
                        .FindValidSingleMobTarget(source, preferredTarget, ract);

                    if (target != null)
                    {
                        return target;
                    }
                }
            }

            // Fallback: 如果没有伤害历史，尝试使用 LastTarget
            if (fallbackToLastTarget && ract.LastTarget is { Valid: true })
            {
                return ract.LastTarget;
            }

            // 没有找到任何有效目标
            return null;
        }
    }
}
```

**设计说明**：
- `fallbackToLastTarget` 允许在没有伤害历史时回退到旧逻辑
- 这样可以支持通过UI点击手动设置的第一个目标

## 第五部分：注意事项和最佳实践

### 5.1 常见陷阱

#### ❌ 陷阱1: 忘记取消事件订阅

**错误代码**：
```csharp
public void Initialize(MobData owner)
{
    this.owner = owner;
    owner.OnDamageDealt.AddListener(OnDamageDealt);
    // ❌ 没有对应的 Cleanup() 方法
}
```

**后果**: 内存泄漏，死亡的单位仍然在接收事件

**正确做法**：
```csharp
public void Cleanup()
{
    if (owner != null)
    {
        owner.OnDamageDealt.RemoveListener(OnDamageDealt);
    }
}
```

#### ❌ 陷阱2: 自我伤害循环

如果不检查 `info.flags`，可能会记录DOT、反伤等间接伤害，导致奇怪的行为。

**正确做法**：
```csharp
// 只记录直接伤害
if (info.flags.HasFlag(Consts.DamageHealFlags.Indirect))
    yield break;
```

#### ❌ 陷阱3: 序列化循环引用

`MobData` 包含 `DamageTargetTracker`，`DamageTargetTracker` 包含 `owner: MobData`，如果都被序列化会导致问题。

**正确做法**：
```csharp
[System.NonSerialized]  // ✅ 不序列化 owner
private MobData owner;
```

### 5.2 性能考虑

#### 目标列表大小限制

如果一场战斗持续很久，`damagedTargets` 列表可能会很大。可以考虑添加限制：

```csharp
private const int MAX_RECORDS = 20;  // 最多记录20个目标

public void RecordDamageTarget(MobData target)
{
    if (target == null)
        return;

    damagedTargets.RemoveAll(r => r.target == target);
    damagedTargets.Add(new DamageTargetRecord(target, Time.time));

    // 限制列表大小，移除最旧的记录
    if (damagedTargets.Count > MAX_RECORDS)
    {
        // 按时间戳排序，移除最旧的
        damagedTargets = damagedTargets
            .OrderByDescending(r => r.timestamp)
            .Take(MAX_RECORDS)
            .ToList();
    }
}
```

#### 定期清理失效目标

可以定期清理已死亡的目标记录：

```csharp
/// <summary>
/// 清理所有已死亡的目标记录
/// </summary>
public void CleanupDeadTargets()
{
    damagedTargets.RemoveAll(r => r.target == null || r.target.isDead);
}
```

在合适的时机调用（如回合结束时）：

```csharp
// 在 MobData 的回合结束事件中
private IEnumerator OnNextTurn(MobData mob)
{
    damageTargetTracker?.CleanupDeadTargets();
    // ... 其他回合逻辑 ...
    yield break;
}
```

```csharp
public struct DamageTargetRecord
{
    public MobData target;
    public float timestamp;
    public int damageDealt;  // 新增：累计伤害

    // 计算优先级得分
    public float GetPriorityScore()
    {
        float timeScore = timestamp;  // 最近伤害的得分高
        float damageScore = damageDealt * 0.01f;  // 伤害越高得分越高

    }
}
```
